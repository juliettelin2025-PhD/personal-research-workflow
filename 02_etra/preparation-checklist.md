# ETRA／論文發表準備清單

## 論文與內容

- [ ] 確認發表題目、摘要與主要研究問題。
- [ ] 用一句話說明研究的重要性。
- [ ] 整理研究設計、資料來源與分析方法。
- [ ] 準備三個主要發現與每項發現的證據。
- [ ] 說明研究限制、倫理考量與下一步。

## 簡報與練習

- [ ] 完成投影片初稿。
- [ ] 每張投影片只保留一個核心訊息。
- [ ] 練習在規定時間內完成發表。
- [ ] 預想三個可能問題並寫下回答要點。
- [ ] 請同儕或指導者給一次回饋。

## 發表前一天

- [ ] 確認檔案備份、投影設備與網路需求。
- [ ] 準備 PDF 備份與講稿提綱。
- [ ] 睡眠與時間安排已確認。
