# Personal Research Workflow

一套可重複使用的個人研究工作流，協助管理修課、論文發表／ETRA 準備，以及可長期累積的研究筆記與專案。

## 適用對象

- 想把課程、閱讀與作業整理成可回顧系統的研究生
- 正在準備論文發表、ETRA 或研究申請的人
- 希望建立個人知識庫與研究作品集的學習者

## 先從這裡開始

1. 將新想法、檔案與連結先放入 `00_inbox`。
2. 每週把資料歸類到課程、論文發表／ETRA、來源、筆記或專案。
3. 每一則研究筆記都記下來源、日期、自己的摘要與下一步。
4. 完成工作後保留過程與模板，讓下一次能更快開始。

## 資料夾結構

```text
00_inbox/       暫存尚未整理的想法、檔案、連結與待辦
01_coursework/  課程、作業、閱讀、課堂筆記與反思
02_etra/        論文發表／ETRA 的準備、練習、申請與證明資料
03_sources/     文獻、網站、書目與資料來源紀錄
04_notes/       可重複使用的研究筆記、概念與方法整理
05_projects/    個別研究專案、分析、草稿與成果
06_templates/   閱讀、筆記、研究、寫作與回饋模板
99_archive/     已完成、暫停或不再使用的資料
```

## 建議的每週整理流程

- 清空或整理 `00_inbox`。
- 為每個新資料補上來源與日期。
- 寫下一個可行動的小步驟，例如「閱讀第 3 節」或「整理三篇文獻」。
- 將可再次使用的內容放進 `04_notes` 或 `06_templates`。

## 給研究生的使用方式

1. 建立自己的副本或資料夾，避免直接改動他人的工作。
2. 為每門課在 `01_coursework` 建立一個子資料夾；檔名可用 `YYYY-MM-DD_主題`。
3. 為每個研究計畫在 `05_projects` 建立子資料夾，至少包含目標、資料來源、進度與下一步。
4. 不要上傳含有學生個資、未公開研究資料或需要保密的檔案。
5. 與指導者或同儕協作前，先確認此 repository 的分享權限與資料規範。

## 接下來可以做的事

- 在 `01_coursework` 建立目前修讀的第一門課。
- 在 `02_etra` 建立一份準備清單。
- 在 `06_templates` 建立第一份閱讀筆記模板。
- 每週固定安排 20 分鐘，維護這套系統。

## 分享與改用

目前此 repository 為私人空間。若日後要提供給學生使用，建議先移除個人或敏感資料，再以範本 repository 或副本的方式分享。
