# 質性研究（Qualitative Research）

本資料夾用來管理本學期的課堂內容、閱讀、作業與研究反思。

## 本週先做三件事

1. 在 `class-notes/` 記錄課堂重點與問題。
2. 在 `reading-notes/` 為每篇指定閱讀建立一份筆記。
3. 在 `assignments/` 記下作業要求、截止日期與下一步。

## 建議結構

```text
class-notes/     課堂筆記與討論問題
reading-notes/   文獻閱讀筆記
assignments/     作業說明、草稿與繳交紀錄
reflections/     方法反思與研究者位置性筆記
```

## 每週 20 分鐘維護

- 5 分鐘：把新資料移入正確資料夾。
- 10 分鐘：補上閱讀與課堂筆記的來源、日期、摘要。
- 5 分鐘：寫下下一個最小行動。

## 研究提醒

質性研究重視脈絡、研究者位置性與倫理。請勿在公開 repository 放入受訪者個資、逐字稿原始資料或其他未公開研究資料。
